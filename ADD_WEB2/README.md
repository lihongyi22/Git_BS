# WEB2 决策实验平台

在 A1_WEB 重建版基础上的 WEB2 试验目录。

当前这一版先聚焦两个低负担改动：

- 删除血糖曲线每个点下方的相对时间标签，减少扫读负担。
- 把“前/中/后”的语义从点颜色迁移到半透明区域配色上，降低点位颜色噪音。

重新构建实验流程进行讨论：


Python 版实验系统（不依赖 R），实现：

- 组内设计，3 因子：情景（2）× 媒介（2）× 风格（2）= 8 个条件
- 默认重复 2 次，总任务 16；可改为 3/4 次（总任务 24/32）
- 8 组拉丁方顺序分配
- 每个任务双阶段：初始决策 + 信心 -> 建议 -> 再决策 + 信心
- 前测 / 后测量表
- 数据库存储被试、任务计划、日志、量表
- CSV 导出

## 启动

1. 进入后端目录
2. 安装依赖
3. 启动接口服务

```bash
pip install -r requirements.txt
uvicorn app.main:app --host 127.0.0.1 --port 8000 --reload
```

打开 http://127.0.0.1:8000 访问系统
