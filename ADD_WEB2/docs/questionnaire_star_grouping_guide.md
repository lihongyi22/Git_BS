# 问卷星分组指标设计说明（供前期问卷使用）

本文件用于指导问卷星收集“被试分层与后续匹配”所需指标。主实验系统不内置该问卷。

## 目标

1. 获取基础人口学和患者信息。
2. 获取可用于与既有 T2DM 群体匹配的数值型特征。
3. 对“记不清数值”的被试提供区间选项，避免缺失。

## 变量结构建议

1. 基本信息：姓名、联系电话、性别、年龄、病程。
2. 关键医学指标（数值或区间二选一）：
   - 最近 HbA1c（数值 %）或区间（<7.0 / 7.0-7.9 / 8.0-8.9 / 9.0-9.9 / >=10.0）
   - 空腹血糖（mmol/L）或区间（<6.1 / 6.1-6.9 / 7.0-7.9 / 8.0-8.9 / >=9.0）
   - 餐后2小时血糖（mmol/L）或区间（<7.8 / 7.8-10.9 / 11.0-13.9 / 14.0-16.9 / >=17.0）
3. 治疗方式：生活方式/口服药/胰岛素/联合。
4. 自我管理行为：运动频率、低血糖经历频率、夜间异常症状。

## 二选一录入规则

每个关键指标设置两题：

1. 数值题（可空）
2. 区间题（可选）

清洗规则：

1. 若数值题有值，优先使用数值。
2. 若数值题为空且区间有值，映射为区间中位数用于建模。
3. 若两者都空，标记 missing 并在匹配时降权处理。

## 建议导出字段

1. `subject_id`：与主实验一致（必须）
2. `age`、`gender`
3. `diabetes_years`
4. `hba1c_value`、`hba1c_bin`
5. `fpg_value`、`fpg_bin`
6. `ppg2h_value`、`ppg2h_bin`
7. `therapy_type`
8. `exercise_freq`
9. `hypo_freq`

## 与主实验对接

1. 在主实验建被试时，使用同一 `subject_id`。
2. 匹配结果字段建议：`matched_group`、`match_confidence`。
3. 若问卷侧尚未匹配完成，先允许主实验进入，后续补写匹配字段。
