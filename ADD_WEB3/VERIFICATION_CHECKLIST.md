## 🐛 如果出现问题

| 问题 | 排查步骤 |
|------|---------|
| 字体没有变大 | 在 F12 开发者工具中检查 body 的 font-size 是否为 18px |
| 按钮点不了 | 检查 F12 console 是否有 JavaScript 错误 |
| 颜色还是棕色 | 清空浏览器缓存（Ctrl+Shift+Delete）后刷新 |
| 建议区始终显示 | 检查 JS 是否有错误，或 .advice-panel 的 display 样式 |
| 响应式异常 | 检查浏览器宽度是否真的改变了 |
