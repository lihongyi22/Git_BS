# WEB3 决策实验平台

基于 `ADD_WEB2` 复制出的 WEB3 升级版，默认使用独立本地端口，避免与 WEB2 的浏览器缓存和服务进程互相干扰。

## 启动

```bash
cd backend
pip install -r requirements.txt
uvicorn app.main:app --host 127.0.0.1 --port 8003 --reload
```

访问地址：

```text
http://127.0.0.1:8003
```

也可以在项目根目录运行：

```powershell
.\run_backend.ps1
```

## WEB3 关键升级

- 新增培训阶段、操作练习和理解确认题，通过后才解锁正式实验。
- 统一建议前/建议后信心评分文案。
- 实验任务固定为 2 个媒介模块、每模块 8 轮、总计 16 轮。
- 拉丁方顺序、媒介顺序、实例分配和选项随机呈现按实验需求实现。
- 记录 WOA、信心变化、选项顺序、专家评分、休息时长和培训完成时间。
- 管理后台记录页新增进度看板、单被试导出、全部汇总导出和实验顺序管理。
