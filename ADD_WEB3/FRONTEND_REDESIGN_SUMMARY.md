## 🚀 使用指南

### 启动后端
```powershell
cd d:\PERSONAL个人文件\毕设文件\ALSTM代码\PLATFORM\EXP_WEB_PY_THESIS_NEW\backend
python -m uvicorn app.main:app --reload --host 127.0.0.1 --port 8000
```

### 打开前端
浏览器访问：`http://127.0.0.1:8000`

### 创建新被试
1. 首页 → 填写被试信息
2. 选择重复次数（2/3/4）
3. 点击「创建并开始前测」
4. 完成前测 5 题
5. 进入实验

### 实验流程
- **步骤1**：看血糖数据，**不看建议**，做初始决策 + 评分信心
- 提交 → **步骤2**：看建议，可改变决策 + 再评分信心
- 提交任务 → 加载下一任务
